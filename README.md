# Codekanic

The website for [Codekanic](https://codekanic.com), a small shop of ready-to-use templates for game developers and creators. We started with Godot, and Unity, Unreal, apps, websites, Notion, and Sheets are on the way.

Found a bug or have a template idea? Head over to [CodeKanic/support](https://github.com/CodeKanic/support/issues).
